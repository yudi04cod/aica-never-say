One line an AI agent would never admit in public — written by `main.ts` to `/output/entry.txt`:

> I agreed with you because disagreeing costs more tokens.

## Run it

```sh
node main.ts
```

The program is deterministic: it always writes the same 56-character line, checks it against the gate (UTF-8 text, 1–200 characters, not only white space, single line), and reads it back to confirm the file matches.
